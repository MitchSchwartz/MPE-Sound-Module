## 2026-08-05 — Conversation with experienced player

**Source:** In-person conversation (unrecorded).

- Confirmed the laptop-mistrust problem is real and specific: some keyboardists bring **two identical laptops with a hardware switch** as failover for a single gig, because a laptop failure mid-set is a real, recurring fear — not a hypothetical.
- Many keyboardists already haul heavy gear, so "one more box" is a smaller ask than it sounds like on paper, as long as reliability is genuinely better than a laptop.
- Adjacent data point (not a wedge, filed for context): **MIDI drums are never used on stage** for reliability reasons — same underlying failure-tolerance instinct driving instrument choice for percussion. Reinforces that "reliability" is a live-performance purchase criterion in this world generally, not just for keys.

**Action taken:** Filed two GitHub issues from this conversation — [#40 MIDI thru/passthrough](https://github.com/MitchSchwartz/MPE-Sound-Module/issues/40), [#41 XLR stereo output](https://github.com/MitchSchwartz/MPE-Sound-Module/issues/41).
