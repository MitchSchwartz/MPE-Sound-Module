## Root cause

`cur="$(mpe_meter_xruns_read)"` runs `mpe_meter_assert_live` in a **command-substitution subshell**. `MPE_METER_LAST_AGE_S` is set inside the subshell but not exported to the parent. With `set -u`, referencing it on the log line aborts the soak — exit 0 on the read masked the failure until minute 1.

Same class as occurrence ten (header-only silence). `measure-soak.sh` already avoids this via `_read_xruns_or_blind` (no command substitution).
