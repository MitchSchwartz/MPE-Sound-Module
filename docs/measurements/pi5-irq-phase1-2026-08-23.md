## Pi 4 map on Pi 5 — partial verdict

| Pi 4 assumption | Pi 5 |
|-----------------|------|
| `irqaffinity=0,1` keeps IRQs off cores 2–3 | **Partially** — mask is 0–1 but delivery piles on **CPU0** |
| `CPUAffinity=2-3` for jackd/surge | **Works** — verified taskset |
| Movable IRQ script (41/42/43…) | **No-op** — wrong numbers, not writable |
| v3d hygiene | **Done** — blacklisted |

**Conclusion:** Keep **2–3 for audio**, **0–1 for UI + poly governor**. Do not enable
`mpe-irq-affinity` (Pi 4 IRQ list). IRQ contention on **CPU0** (usb1 + i2c + Wi‑Fi) is the
Pi 5-specific risk — not fixable via `/proc/irq` today; focus on load reduction (Wi‑Fi idle
traffic, headless measure profile) before cmdline experiments.
