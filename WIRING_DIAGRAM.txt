SIGNAL FLOW
===========

Performance Signal Path:
  Roli → USB MIDI (MPE) → Surge XT → JACK → ALSA → S3 → Audio Out

Control Signal Path:
  Encoders → GPIO → Python → MIDI CC → Surge XT (parameter changes)

Future Display Path:
  Surge XT → OSC → Python → SPI → Display (patch name)

POWER REQUIREMENTS
==================

Raspberry Pi Official Power Supply:
  - Pi 4: 5V 3A (15W)
  - Pi 5: 5V 5A (27W)

Estimated Power Draw:
  - Pi: 6W (under load)
  - Sound Blaster S3: 2W (USB powered)
  - Roli: Powered via USB from Pi
  - Total: ~10W

All USB devices powered from Pi - no external power needed.

TROUBLESHOOTING TIPS
====================

Encoder Not Responding:
  1. Check 3.3V present: gpio readall
  2. Verify wiring: CLK/DT not swapped
  3. Test GPIO: python3 -c "from gpiozero import Button; b=Button(17); print('Press:', b.is_pressed)"

No Audio:
  1. Check USB: lsusb (should see Sound Blaster)
  2. Check JACK: jack_lsp -c (should see connections)
  3. Check volume: alsamixer (not muted)

No MIDI:
  1. Check USB: lsusb (should see Roli device)
  2. Check MIDI: aconnect -l (should list Roli)
  3. Test MIDI: aseqdump -p <roli-port>


SAFETY NOTES
============

- DO NOT connect 5V to GPIO pins (use 3.3V for encoders)
- DO NOT hot-swap GPIO connections (power off first)
- Ensure proper cooling (Pi can throttle at 80°C+)
- Use official Pi power supply (poor power = audio glitches)
